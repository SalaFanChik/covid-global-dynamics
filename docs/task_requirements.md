# Требования к итоговому проекту (выписка из документа «Темы финальных проектов ADA»)

Дисциплина: Programming for Data Analysis and Database. В документе преподавателя программа названа «Big Data Analysis (магистратура)»; фактическая образовательная программа команды — 7M06103 Applied Data Analytics (магистратура), так она и указана во всех материалах проекта.
Тема № 10: **COVID-19 Global Dynamics** — Analyze waves, vaccination, and mortality across countries.
Датасет: Our World in Data — https://github.com/owid/covid-19-data. Инструменты: Pandas, Plotly, Dash.
Фокус: Wave detection + interactive dashboard. Команда: ADA-2602M — Serikov Alikhan, Mashina Veronika, Mukhamejanova Dilnaz.

## I. Общие требования
- Тема утверждается преподавателем. Команда 2–3 человека: вклад каждого указывается в отчёте и презентации.
- Python 3.x. Запуск в консоли или Google Colab / VS Code / PyCharm. Все библиотеки с версиями — в requirements.txt.
- Сдаётся: исходный код (.py/.ipynb); файлы данных (.csv/.json/.txt/.parquet/.db) или ссылка на источник, если объём велик;
  README.md с описанием и инструкцией по запуску; письменный отчёт (данные, методы, результаты, выводы); презентация (.pptx или .pdf).
- Код — в репозитории GitHub. Отчёт и презентация — в Moodle не позднее чем за 2–3 дня до итогового экзамена.
- Защита: демонстрация, объяснение логики программы, архитектуры кода и результатов.
- Расширения (ML, доп. визуализации, интеграции) по согласованию с преподавателем — до 5 бонусных баллов.

## II. Технические требования (обязательный функционал)
1. Функциональное программирование — не менее 5 функций (помимо main), логически разделяющих функционал.
2. Структуры данных — активное использование list и dict.
3. Условная логика — if / elif / else.
4. Циклы — for и/или while (обработка данных, меню, повторный ввод).
5. Работа с файлами — чтение и запись (.txt, .csv, .json, .parquet), например сохранение результатов анализа.
6. Обработка ошибок — try...except хотя бы для одного типа ошибок (некорректный ввод, отсутствие файла).
7. Пользовательский интерфейс — консольное меню («1 – Загрузить данные», …, «Выход») или мини-дашборд Streamlit/Dash с фильтрами.
8. Модульность — несколько файлов .py с импортами; стандартные библиотеки (os, pathlib, datetime, json).
9. Обоснование подхода — сравнение не менее двух подходов и baseline (CSV vs Parquet, Pandas vs SQL, модели);
   критерии: метрики качества, время выполнения, потребление памяти.
10. БД и SQL — загрузка в SQLite или PostgreSQL, ER-диаграмма, не менее 8 SQL-запросов (JOIN, GROUP BY/HAVING,
    подзапросы или CTE, оконные функции), загрузка результатов в Pandas.
11. Объём данных — рекомендуется ≥ 500 тыс. строк или 200 МБ; обработка с учётом памяти: chunksize, оптимизация типов, Parquet.
    Исключения согласуются с преподавателем.

## III. Cluster 2: Exploratory Analytics, Time Series & Dashboards — обязательные задачи
- EDA: описательная статистика, пропуски, выбросы (IQR/boxplot), типы признаков.
- Временные ряды: resample, скользящие средние, сезонная декомпозиция.
- Корреляционный анализ (corr, heatmap).
- 4–5 визуализаций, из них не менее 1 интерактивной (Plotly).
- Хранение очищенных данных в SQLite, выборки через SQL.
- Мини-дашборд Streamlit/Dash с фильтрами (год, регион, категория).
- Сравнение простого прогноза с baseline: naive или seasonal naive против скользящего среднего или Linear Regression (MAE).
